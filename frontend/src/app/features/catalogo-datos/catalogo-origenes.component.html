Agregar varios servidores SQL Server

Pega un servidor por línea. Formatos: host,puerto, host:puerto, host\instancia o solo host (puerto 1433). Opcional: nombre después de |. Las líneas que empiezan por # se ignoran. Al registrar solo se guarda el servidor (host y puerto): no se guarda ningún usuario ni clave. El usuario y la clave de abajo son únicamente para probar la conexión ahora mismo y se descartan.

Autenticación de dominio (Windows) con tu usuario de red. Si la clave está mal, cada intento cuenta para el bloqueo de la cuenta; por eso la prueba se detiene sola tras dos rechazos seguidos. Sin DOMINIO\ se usa login de SQL Server. Para tu usuario de red escribe DOMINIO\usuario. Solo hace falta ver bases y tablas: si la cuenta no ve esquemas o columnas, el catálogo se arma con lo que alcance a leer. Con «Encryption: Mandatory» en SSMS deja marcada la conexión cifrada y confiar en el certificado.
